# facaria-midia

Arquivos de mídia públicos do site da Facaria Aliaga, servidos pelo CDN do jsDelivr:

`https://cdn.jsdelivr.net/gh/gabriel-oculto/facaria-midia@<tag>/<caminho>`

Sempre referenciar por tag (ex.: `@v1`) — o cache do jsDelivr por tag é permanente.
Para trocar um arquivo: novo commit + nova tag + atualizar a URL no tema.
